# MoveIt: Global Education for Indian Students

**MoveIt** is a full-stack platform designed to bridge the gap between Indian students and international education. It allows users to find university courses tailored specifically to their academic backgrounds and competitive exam scores.

### Demo Video
Since the live database is currently archived, please watch the full functionality here:
[**demo video**](https://drive.google.com/file/d/1_mFe4ixQtuE0oL5Evsb97mg3BdwGx0dC/view)

### Tech Stack
* **Frontend:** React.js
* **Backend/BaaS:** Supabase (Authentication & PostgreSQL)
* **Database Management:** SQL (Initial architecture built with Prisma)
* **Deployment:** [Live on Vercel](https://moveit-4dww6sf99-stutis-projects-b4a5789c.vercel.app/)

### Features
* **Dynamic Profiles:** User authentication and profile creation via Supabase, allowing students to input educational history and test scores.
* **Recommendation Engine:** A filter-based system that matches user profiles to specific university courses.
* **Direct Navigation:** Integrated links to detailed university pages for seamless research.
* **Optimized Architecture:** Migrated backend logic from Prisma to Supabase’s built-in client and dashboard, streamlining data flow and reducing backend overhead.
* **Custom Data Schema:** Designed and populated the PostgreSQL database using SQL with a manually curated dataset of university information.
